# ForgeFit — Dominio funcional y modelo mínimo

## Flujo de entrenamiento
Día → bloque → ejercicio individual o biserie → series registradas → descanso → siguiente bloque → resumen. Biserie A1 y A2: completar ambos antes del descanso principal; se admite cambio de orden, pausa y edición. Persistir progreso tras cada cambio.

## Registro de serie
`exercise_id`, `session_id`, `block_id`, `set_index`, `weight_kg`, `reps`, `rir`, `tempo_eccentric_seconds`, `rest_seconds`, `notes`, `completed_at`; validación, unidades y correcciones. Evitar atribuir tempo real si solo es objetivo.

## Progresión
Rango principal 6–10. Sugerir revisar aumento de carga cuando todas las series cumplen el límite superior, técnica confirmada y margen RIR consistente. Sugerencia ≠ cambio automático. Registrar razones. Datos insuficientes → ninguna sugerencia.

## Estadísticas
Volumen estimado = suma(peso × repeticiones) para ejercicios con cargas comparables; series, constancia, tendencia de peso/reps por ejercicio, distribución semanal de series por músculo. No presentar volumen como medida directa de crecimiento o fatiga.

## Seguridad y accesibilidad
Instrucciones de ejecución, control de la fase negativa, descansos, opciones de modificación. No recomendar tests máximos ni técnicas forzadas como necesarias. Toda información anatómica visual debe tener alternativa textual.
